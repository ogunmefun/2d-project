# Lantern Garden desktop icon

Created November 23, 2026 using the built-in image generation tool.

Source: `UnityProject/Assets/Branding/lantern-garden-icon.png`.
Desktop format: `PLAY THE GAME/LanternGarden.ico`, containing 16, 24, 32, 48, 64, 128, and 256-pixel images. Pillow was used only for ICO format conversion and resizing.

The same artwork is assigned as the Unity application's default icon.

## Final generation prompt

Use case: stylized-concept. Asset type: square Windows desktop game icon for Lantern Garden, a beginner-friendly low-poly 3D collecting game. Create one polished icon, not a mockup. A large friendly black-metal garden lantern glowing warm golden yellow, with one small faceted golden crystal and two sage-green leaves at its base. Simple chunky low-poly geometry matching a cozy 3D garden game. Deep teal square background, strong clean silhouette, restrained soft lighting. Center the lantern and fill most of the canvas, leave a small safe margin. Must remain legible at 32 to 64 pixels. No words, letters, numbers, UI, border labels, or extra scenery.
