# Lantern Garden complete submission

Submit `LanternGarden-Complete-Submission-v1.0.1.zip` or the [GitHub release](https://github.com/ogunmefun/2d-project/releases/tag/lantern-garden-v1.0.1-submission), depending on your course's accepted format.

| Folder or file in the extracted package | Contents |
| --- | --- |
| `00-START-HERE.txt` | Plain-text launch and review instructions |
| `README.md` | Download/run guide, controls, troubleshooting, source and build instructions |
| `PLAY THE GAME/LanternGarden.exe` | Playable Windows game; keep adjacent files and folders together |
| `PLAY THE GAME/LanternGarden.ico` | Custom lantern thumbnail for shortcuts |
| `UnityProject/Assets` | Saved scene, ten prefabs, meshes, materials, scripts, and icon artwork |
| `UnityProject/Packages` | Unity package manifest and locked dependencies |
| `UnityProject/ProjectSettings` | Editor version, input, graphics, and build configuration |
| `Docs` | Professor synopsis, beginner guide, screenshots, and verification reports |
| `Tools` | Reproducible build and packaging scripts |
| `PACKAGE-MANIFEST.sha256` | Integrity inventory for the package contents |

Unity recreates import caches such as Library and Temp. Those caches, personal editor settings, previous ZIPs, machine-specific desktop shortcuts, and debug-only build backups are excluded. All files needed to play, inspect, or rebuild the game are included. The game files are the verified 1.0.1 build; this submission adds documentation and packaging.

## Suggested demonstration

Launch the game, move and jump, collect a crystal, pause and open Help, compare shadows on/off, then collect the remaining crystals and walk through the arch. In Unity, show the saved scene, the prefabs, and the directional and lantern lights. Review `VERIFICATION.md` for the exact checks and their limits.

The repository also contains the earlier Neon Relay project. Lantern Garden has its own source folder and release; use the specifically named Lantern Garden download for this submission.
